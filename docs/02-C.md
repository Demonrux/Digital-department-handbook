# Введение в C

> **Уровень:** базовый  
> **Следующая глава:** [Основы](02-basics.md)

**C (Си)** — компилируемый язык программирования общего назначения со статической типизацией. Его создал Деннис Ритчи в Bell Labs в 1969–1973 годах. До сих пор C остаётся одним из самых востребованных языков: на нём написаны ядра операционных систем, драйверы, компиляторы, встраиваемое ПО и множество утилит.

## Зачем нужен C

Изначально C разрабатывался для написания операционной системы **Unix**. Позже его основной сферой стало **системное программирование**:

- операционные системы;
- драйверы устройств;
- компиляторы и интерпретаторы;
- антивирусы и утилиты;
- встраиваемые системы.

Например, ядро **Linux** в значительной степени написано на C.

Но только системным программированием дело не ограничивается. C подходит для любых задач, где важны **скорость работы** и **производительность**: прикладные приложения, серверные программы, даже веб-сайты через **CGI** (Common Gateway Interface). Для графических интерфейсов и веб-приложений обычно выбирают другие инструменты, но круг применения C всё равно очень широк.

Именно поэтому C долгие годы удерживает верхние строчки в рейтингах популярности, например в **TIOBE**.

## Язык «среднего уровня»

C часто называют языком **среднего уровня** — иногда даже «низкого». Это не про качество, а про то, что он сочетает в себе:

- **высокоуровневые конструкции** — циклы, функции, структуры, удобные для человека;
- **низкоуровневый доступ** — работу с памятью, указателями и битами, как в ассемблере.

В итоге вы можете управлять программой на высоком уровне и при этом при необходимости опускаться до работы с конкретными адресами в памяти и аппаратной частью.

## Компилируемый язык

C — **компилируемый** язык. Это значит, что компилятор берёт исходный код и превращает его в **исполняемый файл** с набором машинных инструкций.

Из этого следует два важных момента:

1. **Бинарники непереносимы.** Программа, скомпилированная под одну платформу, скорее всего не запустится на другой — у платформ разные архитектуры и системные вызовы.
2. **Исходный код переносим.** Один и тот же код на C можно скомпилировать под Windows, Linux, macOS и другие системы — были бы компилятор и библиотеки под нужную платформу.

## Влияние на другие языки

Синтаксис C лёг в основу множества современных языков: **C++**, **C#**, **Java**, **PHP**, **JavaScript** — все они так или иначе выросли из C.

Отдельно стоит сказать про **C++**. Он произошёл напрямую от C, но со временем языки разошлись. Стандарт **C99** добавил в C особенности, несовместимые с C++. Сейчас это два самостоятельных языка, которые развиваются независимо.

## Основные особенности

| Особенность | Что это значит |
| :--- | :--- |
| **Универсальность** | Один и тот же код компилируется почти на любой платформе — при наличии компилятора |
| **Высокая скорость** | Программы на C работают быстро и предсказуемо |
| **Компактность** | Небольшой размер скомпилированных файлов |
| **Простота** | Мало конструкций и библиотек — язык легко изучать |
| **Низкий уровень** | Прямой доступ к памяти через указатели |

Из-за простоты и небольшого объёма C часто выбирают как **первый язык** для изучения программирования в целом: он не перегружен конструкциями и заставляет понимать, что происходит «под капотом».

## Итог

- **C** — компилируемый язык со статической типизацией, созданный в 1969–1973 годах Деннисом Ритчи.
- Основная сфера — **системное программирование**, но применяется он гораздо шире.
- Это **язык среднего уровня**: удобный синтаксис плюс прямой доступ к памяти.
- Исходный код на C **переносим**, а бинарники — **нет**.
- Синтаксис C стал основой для C++, Java, C#, PHP, JavaScript.
- Ключевые плюсы: **универсальность**, **скорость**, **компактность**, **простота**.
