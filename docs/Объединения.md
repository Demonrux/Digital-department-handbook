# Объединения

**Объединение** (`union`) — тип, похожий на структуру: тоже содержит набор элементов. Но есть ключевое отличие: все элементы объединения имеют **нулевое смещение** и занимают **один и тот же участок памяти**. Они буквально накладываются друг на друга.

## Определение

Синтаксис — как у `struct`, но с ключевым словом `union`:

```c
union имя_объединения
{
    тип элемент1;
    тип элемент2;
    ...
    тип элементN;
};
```

Пример — объединение для хранения символа и его числового кода:

```c
union ascii
{
    int digit;
    char letter;
};
```

`digit` (4 байта) и `letter` (1 байт) **делят одну память**. Размер объединения — по **наибольшему** элементу: здесь 4 байта.

## Инициализация

При инициализации можно задать **только первый элемент**:

```c
union ascii code = {120};   // 120 попадёт в digit
```

Второй элемент (`letter`) напрямую в `{}` указать нельзя. Если нужен он — присваивайте поле:

```c
code.letter = 'x';
```

## Как это работает

```c
#include <stdio.h>

union ascii
{
    int digit;
    char letter;
};

int main(void)
{
    union ascii code;

    code.digit = 120;
    printf("%d - %c\n", code.digit, code.letter);   // 120 - x
    printf("%d - %d\n", code.digit, code.letter);   // 120 - 120

    code.letter = 87;
    printf("%d - %c\n", code.digit, code.letter);   // 87 - W

    return 0;
}
```

- `code.digit = 120` — записали в общую память `120`.
- `code.digit` читает её как `int` → `120`.
- `code.letter` читает её как `char` → `'x'` (ASCII 120).
- После `code.letter = 87` общая память равна `87`, и `code.digit` тоже показывает `87`.

> **Важно:** читать можно **любое** поле, но значение имеет смысл только для того поля, которое **записано последним**. Чтение другого поля даёт «реинтерпретацию» байтов — это может быть не то, что вы ожидали. Для `int`/`char` в примере выше всё однозначно, но для разных типов — уже зависит от платформы (порядок байтов, размеры).

## `typedef` и анонимные объединения

### Анонимное объединение

Если имя типа не нужно — можно сразу объявить переменные:

```c
#include <stdio.h>

union
{
    int digit;
    char letter;
} code1, code2;

int main(void)
{
    code1.digit = 122;
    code2.digit = 84;

    printf("%d - %c\n", code1.digit, code1.letter);
    printf("%d - %c\n", code2.digit, code2.letter);

    return 0;
}
```

Новые переменные этого типа объявить уже не получится.

### `typedef`

Даёт короткое имя:

```c
typedef union
{
    int digit;
    char letter;
} ascii_code;

ascii_code code = { 22 };
```

## Тегированное объединение

Объединение **не знает**, какое поле в нём сейчас «правильное». Чтобы это отслеживать, объединение объединяют с **тегом** — полем-перечислением в охватывающей структуре. Такой тип называется **tagged union**.

```c
#include <stdio.h>

typedef enum {
    NODE_STRING,
    NODE_INT
} node_type;

typedef union {
    int int_value;
    char *str_value;
} node_data;

typedef struct {
    node_type type;
    node_data data;
} node;

void print_node(node n)
{
    if (n.type == NODE_STRING) {
        printf("String: %s\n", n.data.str_value);
    } else if (n.type == NODE_INT) {
        printf("Int: %d\n", n.data.int_value);
    }
}

int main(void)
{
    node n1 = { .type = NODE_INT,    .data.int_value = 22 };
    node n2 = { .type = NODE_STRING, .data.str_value = "Hello World" };

    print_node(n1);
    print_node(n2);

    return 0;
}
```

Вывод:

```text
Int: 22
String: Hello World
```

Это классический приём: **`type` + `data`** вместе образуют «вариант» — значение, которое может быть одного из нескольких типов. Так работают парсеры (токен — число, строка или идентификатор), сетевые протоколы (пакет — запрос, ответ или ping), JSON-парсеры и т.д.

> **Правило:** объединение **всегда** используется вместе с тегом. Без тега невозможно узнать, какое поле сейчас действительно актуально. Это не формальное требование языка, но дисциплина, без которой код становится нечитаемым.

## Указатели на объединения

Синтаксис такой же, как у структур:

```c
#include <stdio.h>

union ascii
{
    int digit;
    char letter;
};

int main(void)
{
    union ascii code = { 45 };
    union ascii *p_code = &code;

    printf("%d\n", p_code->digit);   // 45

    p_code->digit = 89;
    printf("%d\n", code.digit);      // 89

    return 0;
}
```

Работают оба оператора: `(*p).digit` и `p->digit`.

## `struct` vs `union`

| Свойство | `struct` | `union` |
| :--- | :--- | :--- |
| Память | Каждое поле — своё место | Все поля — **одно** место |
| Размер | Сумма размеров + padding | Максимум из размеров |
| Одновременно можно использовать | **Все** поля | **Одно** поле |
| Инициализация | Любое поле (позиционно или по имени) | **Первый** элемент |
| Применение | Объект с несколькими свойствами | Значение-«одно из» (вариант) |

> **`union` — экономия памяти, но с риском.** Размер меньше, зато нельзя одновременно хранить разные поля. Активное поле отслеживается вручную (тег).

---

## Итог

- **`union`** — все элементы делят одну память. Размер — по наибольшему элементу.
- Инициализировать можно **только первый элемент**.
- Изменение одного поля **затирает** остальные (они делят байты).
- Читать поле, в которое не писали, — опасно: байты интерпретируются «как получится».
- С `typedef` и анонимные — как у структур.
- **Тегированное объединение** — `union` + `enum`-тег. Основной способ применения.
- Указатели на `union` — синтаксис идентичен структурам.
