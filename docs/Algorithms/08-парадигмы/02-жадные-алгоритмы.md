# Жадные алгоритмы

**Жадный алгоритм** на каждом шаге делает **локально оптимальный** выбор в надежде, что из локальных оптимумов сложится глобальный. Это самый простой и быстрый подход к оптимизационным задачам — но работает он **не всегда**.

Жадные алгоритмы привлекательны тем, что не требуют хранить состояние, перебирать варианты или строить таблицы. Одно правило — идём вперёд. Когда задача подходит под жадную стратегию, это даёт **простейшее и эффективнейшее** решение.

## Когда жадный алгоритм работает

Жадная стратегия корректна, если задача обладает двумя свойствами.

**Свойство жадного выбора** — можно доказать, что локально оптимальный выбор входит в какое-то глобально оптимальное решение. Если это так, жадный алгоритм найдёт оптимум.

**Оптимальная подструктура** — оптимальное решение задачи содержит оптимальные решения подзадач.

Второе свойство есть и у динамического программирования. Разница в том, что жадный алгоритм делает выбор **один раз** и не пересматривает его, а ДП рассматривает **все варианты**.

**Как отличить.** Если задача подходит под жадную стратегию — используйте жадный алгоритм: он проще и быстрее. Если нет — нужно ДП. Универсального способа определить это нет — приходится **доказывать** свойство жадного выбора для каждой задачи отдельно.

## Задача о выборе заявок

**Постановка.** Есть `n` заявок, каждая с временем начала и окончания. Нужно выбрать **максимальное** число заявок, которые не пересекаются.

**Жадная стратегия.** Сортируем заявки по **времени окончания** и берём каждую, которая начинается после окончания предыдущей выбранной.

Почему именно по окончанию? Если сортировать по началу или по длительности — получим неоптимальный результат. Заявка, которая заканчивается раньше, оставляет больше времени для следующих.

**Сложность:** `O(n log n)` на сортировку и `O(n)` на проход. Это оптимально.

## Кодирование Хаффмана

**Постановка.** Есть алфавит, для каждого символа известна частота. Нужно построить **префиксный код** минимальной средней длины.

**Префиксный** означает, что код ни одного символа не является префиксом кода другого. Это позволяет однозначно декодировать сообщение слева направо.

**Жадная стратегия.** Строим дерево снизу вверх: берём два символа с **наименьшими** частотами, объединяем в узел с суммарной частотой, возвращаем узел в очередь. Повторяем, пока не останется один узел — корень.

Путь от корня к символу — его код: левое ребро — `0`, правое — `1`. Частые символы окажутся ближе к корню (короткий код), редкие — дальше (длинный).

**Сложность:** `O(n log n)` при использовании **приоритетной очереди** (кучи).

Кодирование Хаффмана применяется в **ZIP, JPEG, MP3** — везде, где нужно сжатие без потерь.

## Размен монет

**Постановка.** Есть монеты номиналов `1, 5, 10, 25` (как в США). Нужно набрать сумму `S` **минимальным** числом монет.

**Жадная стратегия.** Берём самую крупную монету, которая не превышает остаток, и продолжаем.

Для этой системы номиналов жадный алгоритм **работает**. Но если номиналы `1, 3, 4`, а сумма `6` — жадный даст `4 + 1 + 1 = 3` монеты, а оптимально `3 + 3 = 2`. **Жадный не работает.**

Мораль: **нельзя** применять жадный алгоритм к размену монет для произвольной системы номиналов. Нужно либо доказать его корректность, либо использовать динамическое программирование.

## Задача о покрытии

**Постановка.** Есть множество `U` и набор подмножеств. Нужно выбрать **минимальное** число подмножеств, покрывающих всё `U`.

**Жадная стратегия.** На каждом шаге выбираем подмножество, покрывающее **больше всего** ещё непокрытых элементов.

**Жадный алгоритм даёт приближённое решение**, а не оптимальное. Для задачи о покрытии известно, что оптимальное решение — **NP-полная** задача, и жадный алгоритм даёт решение, отличающееся от оптимального не более чем в `ln n` раз. Это **лучшая возможная** гарантия для полиномиального алгоритма.

## Реализация на C

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

// ===== Задача о выборе заявок =====
typedef struct {
    int start;
    int finish;
} Request;

// Сортировка по времени окончания
static int compareByFinish(const void *a, const void *b) {
    const Request *ra = a;
    const Request *rb = b;
    return ra->finish - rb->finish;
}

int selectRequests(Request reqs[], int n) {
    qsort(reqs, (size_t)n, sizeof(Request), compareByFinish);

    int count = 0;
    int lastFinish = -1;

    for (int i = 0; i < n; i++) {
        if (reqs[i].start >= lastFinish) {
            count++;
            lastFinish = reqs[i].finish;
        }
    }
    return count;
}

// ===== Размен монет (жадный, работает для стандартных номиналов) =====
int greedyCoinChange(const int coins[], int k, int sum) {
    int count = 0;
    for (int i = 0; i < k; i++) {
        while (sum >= coins[i]) {
            sum -= coins[i];
            count++;
        }
    }
    return (sum == 0) ? count : -1;
}

// ===== Кодирование Хаффмана: узел дерева =====
typedef struct HuffNode {
    char             symbol;
    unsigned         freq;
    struct HuffNode *left;
    struct HuffNode *right;
} HuffNode;

// Вспомогательная: создать новый узел
static HuffNode* huffNodeCreate(char symbol, unsigned freq,
                                HuffNode *left, HuffNode *right) {
    HuffNode *node = malloc(sizeof(HuffNode));
    if (node == NULL) return NULL;

    node->symbol = symbol;
    node->freq   = freq;
    node->left   = left;
    node->right  = right;
    return node;
}

// Вспомогательная: найти два узла с минимальной частотой
static void findTwoSmallest(HuffNode *nodes[], int n, int *i1, int *i2) {
    *i1 = -1;
    *i2 = -1;

    for (int i = 0; i < n; i++) {
        if (nodes[i] == NULL) continue;

        if (*i1 == -1 || nodes[i]->freq < nodes[*i1]->freq) {
            *i2 = *i1;
            *i1 = i;
        } else if (*i2 == -1 || nodes[i]->freq < nodes[*i2]->freq) {
            *i2 = i;
        }
    }
}

// Построение дерева Хаффмана (простая версия через линейный поиск)
HuffNode* buildHuffmanTree(const char symbols[], const unsigned freqs[], int n) {
    // Массив узлов: сначала листья
    HuffNode **nodes = malloc((size_t)(2 * n) * sizeof(HuffNode *));
    if (nodes == NULL) return NULL;

    for (int i = 0; i < n; i++) {
        nodes[i] = huffNodeCreate(symbols[i], freqs[i], NULL, NULL);
    }

    int count = n;

    // n - 1 раз объединяем два наименьших
    while (count > 1) {
        int i1, i2;
        findTwoSmallest(nodes, count, &i1, &i2);

        HuffNode *merged = huffNodeCreate(
            '\0',
            nodes[i1]->freq + nodes[i2]->freq,
            nodes[i1],
            nodes[i2]
        );

        // Заменяем первый узел объединённым, второй зануляем
        nodes[i1] = merged;
        nodes[i2] = NULL;

        // Сдвигаем NULL-ы в конец
        int write = 0;
        for (int i = 0; i < count; i++) {
            if (nodes[i] != NULL) nodes[write++] = nodes[i];
        }
        count = write;
    }

    HuffNode *root = nodes[0];
    free(nodes);
    return root;
}

// Рекурсивный вывод кодов
void printHuffmanCodes(HuffNode *root, char *buffer, int depth) {
    if (root == NULL) return;

    // Лист
    if (root->left == NULL && root->right == NULL) {
        buffer[depth] = '\0';
        printf("'%c': %s\n", root->symbol, buffer);
        return;
    }

    if (root->left != NULL) {
        buffer[depth] = '0';
        printHuffmanCodes(root->left, buffer, depth + 1);
    }
    if (root->right != NULL) {
        buffer[depth] = '1';
        printHuffmanCodes(root->right, buffer, depth + 1);
    }
}

// Освобождение дерева
void huffTreeFree(HuffNode *root) {
    if (root == NULL) return;
    huffTreeFree(root->left);
    huffTreeFree(root->right);
    free(root);
}

int main(void) {
    // Заявки
    Request reqs[] = {
        { 1, 4 }, { 3, 5 }, { 0, 6 }, { 5, 7 }, { 3, 9 }, { 5, 9 }, { 6, 10 }, { 8, 11 }
    };
    int n = sizeof(reqs) / sizeof(reqs[0]);
    printf("Выбрано заявок: %d\n", selectRequests(reqs, n));   // 3

    // Размен монет (жадный)
    int coins[] = { 25, 10, 5, 1 };
    printf("Размен 63: %d\n", greedyCoinChange(coins, 4, 63));   // 6 (25+25+10+1+1+1)

    // Хаффман
    char     symbols[] = { 'a', 'b', 'c', 'd' };
    unsigned freqs[]   = { 45, 13, 12, 16 };

    HuffNode *root = buildHuffmanTree(symbols, freqs, 4);
    printf("\nКоды Хаффмана:\n");

    char buffer[64];
    printHuffmanCodes(root, buffer, 0);

    huffTreeFree(root);

    return 0;
}
```

### Что важно в реализациях

**Заявки сортируются по окончанию.** Это ключевая идея: рано заканчивающиеся заявки оставляют больше времени для остальных. Сортировка по началу или длительности даёт неоптимальный результат.

**Хаффман — простая версия.** В настоящем коде используют **кучу** для поиска двух минимальных за `O(log n)`. Здесь применён линейный поиск, потому что цель — показать **идею**, а не максимум производительности. Сложность получается `O(n²)` вместо `O(n log n)`.

**Хаффман — дерево удаляется рекурсивно.** Как в BST: сначала дети, потом родитель. Иначе получится утечка.

**Размен монет.** В примере номиналы `25, 10, 5, 1` — стандартные американские. Для них жадный алгоритм работает. Но если бы номиналы были `1, 3, 4` — результат был бы неоптимальным. Это хорошая иллюстрация ограничений жадного подхода.

## Итог

- **Жадный алгоритм** делает локально оптимальный выбор на каждом шаге.
- Корректен, если есть **свойство жадного выбора** и **оптимальная подструктура**.
- **Задача о заявках** — сортировка по времени окончания, `O(n log n)`.
- **Кодирование Хаффмана** — слияние двух наименьших, `O(n log n)` с кучей.
- **Размен монет** — жадный работает для одних номиналов и не работает для других.
- **Задача о покрытии** — жадный даёт приближённое решение с гарантией `ln n`, потому что точное — NP-полное.
- Если жадный алгоритм не работает — используйте **динамическое программирование**.
