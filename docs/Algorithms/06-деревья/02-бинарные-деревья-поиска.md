# Бинарные деревья поиска

**Бинарное дерево поиска** (Binary Search Tree, BST) — структура данных, которая поддерживает операции с динамическими множествами: поиск, минимум, максимум, предшествующий, последующий, вставку, удаление. BST может использоваться и как **словарь**, и как **очередь с приоритетами**.

## Свойство бинарного дерева поиска

Каждый узел BST содержит поле `key` и сопутствующие данные, а также указатели `left`, `right` и `parent` на левого и правого потомков и на родителя. Если потомок или родитель отсутствуют, соответствующее поле содержит `NIL`. Единственный узел, у которого `parent = NIL`, — это **корень**.

**Свойство BST:** если узел `y` находится в левом поддереве узла `x`, то `key[y] ≤ key[x]`. Если `y` в правом поддереве — то `key[x] ≤ key[y]`.

Иначе говоря, все ключи слева — **не больше**, все ключи справа — **не меньше**. Именно это свойство делает BST удобным для поиска: на каждом шаге мы отбрасываем половину поддерева.

Высота дерева играет решающую роль. Если дерево **сбалансировано**, высота — `O(log n)`, и все операции работают за `O(log n)`. Если дерево **вырождено** (все узлы выстроились в одну линию), высота `O(n)`, и BST превращается в обычный связный список.

## Поиск ключа

Процедура поиска начинается с корня и спускается вниз. На каждом узле ключ сравнивается с искомым: если совпал — поиск завершён, если искомый меньше — идём в левое поддерево, если больше — в правое.

```text
TREE_SEARCH(x, k)
1  if x = NIL или k = key[x] then
2      return x
3  if k < key[x] then
4      return TREE_SEARCH(left[x], k)
5  else
6      return TREE_SEARCH(right[x], k)
```

Рекурсия легко превращается в цикл — **итеративная версия** обычно быстрее, потому что не тратит стек:

```text
ITERATIVE_TREE_SEARCH(x, k)
1  while x ≠ NIL и k ≠ key[x] do
2      if k < key[x] then x ← left[x]
3      else x ← right[x]
4  return x
```

Время работы — **`O(h)`**, где `h` — высота дерева.

## Минимум и максимум

Минимальный элемент — это **самый левый** узел. Максимальный — **самый правый**. Логика простая: в BST всё, что слева, меньше, поэтому минимум обязательно окажется в левом поддереве каждого узла, пока это поддерево существует.

```text
TREE_MINIMUM(x)
1  while left[x] ≠ NIL do
2      x ← left[x]
3  return x

TREE_MAXIMUM(x)
1  while right[x] ≠ NIL do
2      x ← right[x]
3  return x
```

Обе процедуры работают за `O(h)`.

## Предшествующий и последующий

**Последующий** (successor) — узел с наименьшим ключом, **большим** чем `key[x]`. **Предшествующий** (predecessor) — с наибольшим ключом, **меньшим** `key[x]`.

```text
TREE_SUCCESSOR(x)
1  if right[x] ≠ NIL then
2      return TREE_MINIMUM(right[x])
3  y ← parent[x]
4  while y ≠ NIL и x = right[y] do
5      x ← y
6      y ← parent[y]
7  return y
```

Логика: если у узла есть **правое поддерево**, то последующий — самый левый узел в этом поддереве. Если правого поддерева **нет** — поднимаемся вверх, пока не найдём узел, который является **левым** ребёнком своего родителя. Этот родитель и есть последующий.

Процедура `TREE_PREDECESSOR` симметрична и ищет самый правый узел левого поддерева или поднимается, пока узел не окажется правым ребёнком. Обе процедуры работают за `O(h)`.

## Вставка

Вставка нового узла `z` начинается с поиска места — мы спускаемся от корня, сравнивая ключи, и запоминаем родителя `y` последнего пройденного узла. Когда доходим до `NIL`, вставляем `z` как левого или правого потомка `y`.

```text
TREE_INSERT(T, z)
1  y ← NIL
2  x ← root[T]
3  while x ≠ NIL do
4      y ← x
5      if key[z] < key[x] then x ← left[x]
6      else x ← right[x]
7  parent[z] ← y
8  if y = NIL then root[T] ← z
9  else if key[z] < key[y] then left[y] ← z
10 else right[y] ← z
```

Время работы — **`O(h)`**.

## Удаление

Удаление — самая сложная операция в BST, потому что нужно обработать **три случая** в зависимости от числа потомков у удаляемого узла.

**Случай 1: у узла нет потомков.** Просто убираем ссылку родителя на него.

**Случай 2: у узла один потомок.** «Склеиваем» родителя с потомком — ссылка родителя указывает на ребёнка удаляемого узла.

**Случай 3: у узла два потомка.** Находим **последующий** узел `y` (самый левый в правом поддереве). У него точно нет левого потомка. Убираем `y` из его текущей позиции и **ставим на место** удаляемого узла.

```text
TREE_DELETE(T, z)
1  if left[z] = NIL или right[z] = NIL then
2      y ← z
3  else
4      y ← TREE_SUCCESSOR(z)
5  if left[y] ≠ NIL then x ← left[y]
6  else x ← right[y]
7  if x ≠ NIL then parent[x] ← parent[y]
8  if parent[y] = NIL then root[T] ← x
9  else if y = left[parent[y]] then left[parent[y]] ← x
10 else right[parent[y]] ← x
11 if y ≠ z then
12     key[z] ← key[y]
13     // копируем сопутствующие данные
14 return y
```

Время работы — **`O(h)`**.

## Реализация на C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct BstNode {
    int              key;
    struct BstNode  *left;
    struct BstNode  *right;
    struct BstNode  *parent;
} BstNode;

typedef struct {
    BstNode *root;
    size_t   count;
} Bst;

void bstInit(Bst *tree) {
    tree->root  = NULL;
    tree->count = 0;
}

// Поиск узла по ключу (итеративный)
BstNode* bstSearch(Bst *tree, int key) {
    BstNode *x = tree->root;
    while (x != NULL && key != x->key) {
        x = (key < x->key) ? x->left : x->right;
    }
    return x;
}

// Минимум в поддереве
BstNode* bstMinimum(BstNode *x) {
    while (x != NULL && x->left != NULL) {
        x = x->left;
    }
    return x;
}

// Максимум в поддереве
BstNode* bstMaximum(BstNode *x) {
    while (x != NULL && x->right != NULL) {
        x = x->right;
    }
    return x;
}

// Последующий узел
BstNode* bstSuccessor(BstNode *x) {
    if (x->right != NULL) {
        return bstMinimum(x->right);
    }
    BstNode *y = x->parent;
    while (y != NULL && x == y->right) {
        x = y;
        y = y->parent;
    }
    return y;
}

// Вставка нового ключа
BstNode* bstInsert(Bst *tree, int key) {
    BstNode *z = malloc(sizeof(BstNode));
    if (z == NULL) return NULL;

    z->key    = key;
    z->left   = NULL;
    z->right  = NULL;
    z->parent = NULL;

    BstNode *y = NULL;
    BstNode *x = tree->root;

    while (x != NULL) {
        y = x;
        x = (key < x->key) ? x->left : x->right;
    }
    z->parent = y;

    if (y == NULL) {
        tree->root = z;
    } else if (key < y->key) {
        y->left = z;
    } else {
        y->right = z;
    }
    tree->count++;
    return z;
}

// Вспомогательная: пересадка поддерева
static void bstTransplant(Bst *tree, BstNode *u, BstNode *v) {
    if (u->parent == NULL) {
        tree->root = v;
    } else if (u == u->parent->left) {
        u->parent->left = v;
    } else {
        u->parent->right = v;
    }
    if (v != NULL) {
        v->parent = u->parent;
    }
}

// Удаление узла
void bstDelete(Bst *tree, BstNode *z) {
    if (z->left == NULL) {
        bstTransplant(tree, z, z->right);
    } else if (z->right == NULL) {
        bstTransplant(tree, z, z->left);
    } else {
        BstNode *y = bstMinimum(z->right);   // последующий
        if (y->parent != z) {
            bstTransplant(tree, y, y->right);
            y->right = z->right;
            y->right->parent = y;
        }
        bstTransplant(tree, z, y);
        y->left = z->left;
        y->left->parent = y;
    }
    free(z);
    tree->count--;
}

// Симметричный обход — выводит ключи в отсортированном порядке
void bstInorder(BstNode *x) {
    if (x == NULL) return;
    bstInorder(x->left);
    printf("%d ", x->key);
    bstInorder(x->right);
}

// Освобождение всего дерева (пост-обход)
void bstFree(BstNode *x) {
    if (x == NULL) return;
    bstFree(x->left);
    bstFree(x->right);
    free(x);
}

int main(void) {
    Bst tree;
    bstInit(&tree);

    int keys[] = { 15, 6, 18, 3, 7, 17, 20, 2, 4, 13, 9 };
    size_t n = sizeof(keys) / sizeof(keys[0]);

    for (size_t i = 0; i < n; i++) {
        bstInsert(&tree, keys[i]);
    }

    printf("Симметричный обход: ");
    bstInorder(tree.root);
    printf("\n");

    // Удаляем корень
    bstDelete(&tree, tree.root);
    printf("После удаления корня: ");
    bstInorder(tree.root);
    printf("\n");

    bstFree(tree.root);
    return 0;
}
```

### Что важно в реализации

**Указатель на родителя.** Поле `parent` нужно для операций `successor` и `delete`. Без него пришлось бы каждый раз искать родителя перебором — это свело бы `O(h)` к `O(n)`.

**Итеративный поиск.** В отличие от рекурсивного, не расходует стек и работает быстрее.

**Операция `transplant`.** Вынесена отдельно, потому что используется в `delete` трижды. Это классический приём — выделить общий код в вспомогательную функцию.

**Освобождение памяти.** `bstFree` обходит дерево в обратном порядке (сначала дети, потом узел), потому что нельзя освободить родителя, не освободив потомков.

## Итог

- **BST** — структура с свойством: левое поддерево ≤ узел ≤ правое поддерево.
- Все операции — `O(h)`, где `h` — высота дерева. Для сбалансированного дерева `O(log n)`, для вырожденного `O(n)`.
- **Поиск** спускается от корня, выбирая левое или правое поддерево.
- **Минимум** — самый левый узел, **максимум** — самый правый.
- **Последующий** — либо минимум правого поддерева, либо первый родитель, у которого узел — левый ребёнок.
- **Вставка** — поиск места + привязка к родителю.
- **Удаление** — три случая: нет потомков, один потомок, два потомка.
- В C нужно хранить указатель на родителя и аккуратно освобождать память.
