# 🌳 Основы Git и GitHub
## Что такое Git?
Git — система контроля версий. Она запоминает \*\*все изменения\*\* в файлах и позволяет вернуться к любой версии. Это как «история» в Google Docs, но мощнее.
**Git ≠ GitHub.** Git — программа на твоём компьютере. GitHub — сайт, где хранятся репозитории в облаке.

## Ключевые понятия
| Термин | Что это      |
| :--- | :---           |
| **Репозиторий**       | Папка с проектом под контролем Git |
| **Коммит**            | Снимок изменений с описанием |
| **Ветка (branch)\*\*  | Отдельная линия разработки |
| **Pull Request (PR)** | Запрос на слияние твоей ветки в основную |
| **Merge**             | Слияние веток |

## Базовые команды
```bash

# Настройка (один раз)
git config --global user.name "Твоё Имя"
git config --global user.email "you@example.com"

# Клонирование репозитория
git clone https://github.com/username/repo.git

# Посмотреть статус
git status

# Создать ветку и переключиться на неё
git checkout -b feature-name

# Добавить изменения в индекс
git add file.md
git add .           # все файлы

# Коммит
git commit -m "Add feature"

# Отправить на GitHub
git push origin feature-name

# Получить последние изменения
git pull
