## Сортировка вставками

На каждом шаге берём очередной элемент и вставляем его в отсортированную часть, сдвигая большие элементы вправо.

```c
void insertionSort(int a[], size_t n) {
    for (size_t j = 1; j < n; j++) {
        int key = a[j];
        size_t i = j;
        while (i > 0 && a[i - 1] > key) {
            a[i] = a[i - 1];
            i--;
        }
        a[i] = key;
    }
}
```

**Сложность:** `O(n²)` в среднем, `O(n)` на почти отсортированных данных.

## Сортировка выбором

Находим минимум в неотсортированной части и ставим его на первое место этой части.

```c
void selectionSort(int a[], size_t n) {
    for (size_t i = 0; i < n - 1; i++) {
        size_t minIndex = i;
        for (size_t j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            int tmp = a[i];
            a[i] = a[minIndex];
            a[minIndex] = tmp;
        }
    }
}
```

**Сложность:** `O(n²)` в любом случае. Но обменов — не больше `n - 1`.

## Пузырьковая сортировка

Сравниваем соседние элементы и меняем их местами, если они в неправильном порядке. Проход повторяется, пока не упорядочим.

```c
void bubbleSort(int a[], size_t n) {
    for (size_t i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (size_t j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;   // уже отсортирован
    }
}
```

**Сложность:** `O(n²)` в среднем, `O(n)` на отсортированном массиве благодаря флагу.

## Шейкер-сортировка

Улучшение пузырьковой: проходы идут то слева направо, то справа налево. Это убирает проблему «тяжёлых» элементов, которые тонут медленно.

```c
void shakerSort(int a[], size_t n) {
    size_t left  = 0;
    size_t right = n - 1;
    bool swapped = true;

    while (swapped) {
        swapped = false;

        // Проход слева направо — «тяжёлые» тонут
        for (size_t j = left; j < right; j++) {
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;
        right--;

        // Проход справа налево — «лёгкие» всплывают
        swapped = false;
        for (size_t j = right; j > left; j--) {
            if (a[j - 1] > a[j]) {
                int tmp = a[j];
                a[j] = a[j - 1];
                a[j - 1] = tmp;
                swapped = true;
            }
        }
        left++;
    }
}
```

**Сложность:** `O(n²)` в среднем, `O(n)` на почти отсортированном массиве.

## Сортировка Шелла

Модификация сортировки вставками: сначала сортируем элементы с шагом `h`, потом уменьшаем `h` до `1`.

```c
void shellSort(int a[], size_t n) {
    // Выбираем начальный шаг
    size_t h = 1;
    while (h < n / 3) {
        h = 3 * h + 1;
    }

    while (h >= 1) {
        // Сортировка вставками с шагом h
        for (size_t i = h; i < n; i++) {
            int key = a[i];
            size_t j = i;
            while (j >= h && a[j - h] > key) {
                a[j] = a[j - h];
                j -= h;
            }
            a[j] = key;
        }
        h /= 3;
    }
}
```

**Сложность:** примерно `O(n^(4/3))` — быстрее, чем `O(n²)`, но медленнее `O(n log n)`.

## Пирамидальная сортировка

Строим **максимальную пирамиду**, затем `n` раз выталкиваем максимум в конец.

```c
// Просеивание вниз: восстанавливает пирамиду
static void heapify(int a[], size_t n, size_t i) {
    size_t largest = i;
    size_t left    = 2 * i + 1;
    size_t right   = 2 * i + 2;

    if (left < n && a[left] > a[largest]) {
        largest = left;
    }
    if (right < n && a[right] > a[largest]) {
        largest = right;
    }

    if (largest != i) {
        int tmp = a[i];
        a[i] = a[largest];
        a[largest] = tmp;

        heapify(a, n, largest);   // просеиваем дальше
    }
}

void heapSort(int a[], size_t n) {
    // Построение пирамиды: от середины к началу
    for (long i = (long)n / 2 - 1; i >= 0; i--) {
        heapify(a, n, (size_t)i);
    }

    // Извлекаем максимум в конец и восстанавливаем пирамиду
    for (size_t i = n; i > 1; i--) {
        int tmp = a[0];
        a[0] = a[i - 1];
        a[i - 1] = tmp;

        heapify(a, i - 1, 0);
    }
}
```

**Сложность:** `O(n log n)` гарантированно, без дополнительной памяти.

> **Замечание:** рекурсивный `heapify` в глубину не превышает `log n` — стек не переполнится.

## Быстрая сортировка

Выбираем опорный элемент, разделяем массив на две части, рекурсивно сортируем каждую.

```c
static void quickSortRec(int a[], long left, long right) {
    if (left >= right) return;

    // Опорный элемент — средний
    int pivot = a[(left + right) / 2];

    long i = left;
    long j = right;

    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;

        if (i <= j) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
            i++;
            j--;
        }
    }

    // Рекурсивно сортируем левую и правую части
    quickSortRec(a, left, j);
    quickSortRec(a, i, right);
}

void quickSort(int a[], size_t n) {
    if (n > 1) {
        quickSortRec(a, 0, (long)n - 1);
    }
}
```

**Сложность:** `O(n log n)` в среднем, `O(n²)` в худшем (когда опорный всегда min или max).

> **Оптимизация.** Чтобы уменьшить шанс худшего случая, опорный элемент выбирают **случайно** или как **медиану из трёх** (первый, средний, последний). Для учебного кода достаточно среднего элемента.

## Сортировка слиянием

Делим массив пополам, сортируем каждую половину рекурсивно, потом сливаем.

```c
// Слияние двух отсортированных частей: a[left..mid] и a[mid+1..right]
static void merge(int a[], int tmp[], size_t left, size_t mid, size_t right) {
    size_t i = left;
    size_t j = mid + 1;
    size_t k = left;

    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            tmp[k++] = a[j++];
        }
    }

    while (i <= mid)   tmp[k++] = a[i++];
    while (j <= right) tmp[k++] = a[j++];

    // Копируем обратно
    for (size_t p = left; p <= right; p++) {
        a[p] = tmp[p];
    }
}

static void mergeSortRec(int a[], int tmp[], size_t left, size_t right) {
    if (left >= right) return;

    size_t mid = left + (right - left) / 2;

    mergeSortRec(a, tmp, left, mid);
    mergeSortRec(a, tmp, mid + 1, right);
    merge(a, tmp, left, mid, right);
}

void mergeSort(int a[], size_t n) {
    if (n < 2) return;

    int *tmp = malloc(n * sizeof(int));
    if (tmp == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    mergeSortRec(a, tmp, 0, n - 1);
    free(tmp);
}
```

**Сложность:** `O(n log n)` в любом случае. Требует `O(n)` дополнительной памяти. **Устойчива.**

## Сортировка подсчётом

Работает для целых чисел из известного диапазона `[0, k]`. Считаем количество каждого значения, потом расставляем.

```c
void countingSort(int a[], size_t n, int k) {
    // k — максимальное значение в массиве
    int *count = calloc((size_t)k + 1, sizeof(int));
    int *out   = malloc(n * sizeof(int));

    if (count == NULL || out == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        free(count);
        free(out);
        exit(1);
    }

    // Считаем количество каждого значения
    for (size_t i = 0; i < n; i++) {
        count[a[i]]++;
    }

    // Префиксные суммы: count[i] = число элементов ≤ i
    for (int i = 1; i <= k; i++) {
        count[i] += count[i - 1];
    }

    // Обходим с конца — для устойчивости
    for (long i = (long)n - 1; i >= 0; i--) {
        out[count[a[i]] - 1] = a[i];
        count[a[i]]--;
    }

    // Копируем обратно
    for (size_t i = 0; i < n; i++) {
        a[i] = out[i];
    }

    free(count);
    free(out);
}
```

**Сложность:** `O(n + k)`. **Устойчива.** Работает только для целых неотрицательных чисел.

## Общий пример

Программа сортирует один и тот же массив разными алгоритмами и проверяет результат.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>

// Все сортировки объявлены выше...

static void printArray(const int a[], size_t n) {
    for (size_t i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
}

static bool isSorted(const int a[], size_t n) {
    for (size_t i = 1; i < n; i++) {
        if (a[i - 1] > a[i]) return false;
    }
    return true;
}

int main(void) {
    int original[] = { 5, 2, 9, 1, 5, 6, 3, 8, 4, 7 };
    size_t n = sizeof(original) / sizeof(original[0]);

    printf("Исходный массив:  ");
    printArray(original, n);
    printf("\n");

    // Проверяем каждый алгоритм на копии
    int a[10];

    memcpy(a, original, sizeof(original));
    insertionSort(a, n);
    printf("Вставками:        ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    selectionSort(a, n);
    printf("Выбором:          ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    bubbleSort(a, n);
    printf("Пузырьковая:      ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    shakerSort(a, n);
    printf("Шейкер:           ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    shellSort(a, n);
    printf("Шелла:            ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    heapSort(a, n);
    printf("Пирамидальная:    ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    quickSort(a, n);
    printf("Быстрая:          ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    mergeSort(a, n);
    printf("Слиянием:         ");
    printArray(a, n);
    printf("  Отсортирован: %s\n\n", isSorted(a, n) ? "да" : "нет");

    memcpy(a, original, sizeof(original));
    countingSort(a, n, 9);   // 9 — максимум в массиве
    printf("Подсчётом:        ");
    printArray(a, n);
    printf("  Отсортирован: %s\n", isSorted(a, n) ? "да" : "нет");

    return 0;
}
```

Пример вывода:

```text
Исходный массив:  5 2 9 1 5 6 3 8 4 7

Вставками:        1 2 3 4 5 5 6 7 8 9
  Отсортирован: да
...
```

### Замечания по реализациям

**Про `size_t` и `long`.** В циклах, идущих вниз, используется `long`, а не `size_t`: беззнаковый тип при `i--` от нуля даст огромное число и зациклится.

**Про `heapify`.** Рекурсивный вызов — не хвостовой, но глубина рекурсии не превышает `log n`, потому что дерево сбалансировано.

**Про `mergeSort`.** Единственная сортировка, которой нужна динамическая память. `malloc` вызывается один раз — под весь вспомогательный массив.

**Про `countingSort`.** Параметр `k` — максимальное значение в массиве. Если числа могут быть отрицательными, нужен сдвиг: `count[a[i] - min]`.

**Про устойчивость.** Устойчивые сортировки — вставками, пузырьковая, шейкер, слиянием, подсчётом. Остальные не гарантируют сохранение относительного порядка равных элементов.

## Итог

- Все реализации принимают `int a[]` и `size_t n`, сортируют массив **на месте** (кроме merge и counting).
- **Вставками, выбором, пузырьковая, шейкер** — простые, `O(n²)`. Для обучения и маленьких массивов.
- **Шелла** — модификация вставками, быстрее `O(n²)`.
- **Пирамидальная, быстрая, слиянием** — `O(n log n)`. Выбор зависит от требований: память, устойчивость, гарантия худшего случая.
- **Подсчётом** — линейная, но только для целых из известного диапазона.
- В циклах вниз используйте **знаковый** тип (`long`), чтобы избежать проблем с `size_t`.
