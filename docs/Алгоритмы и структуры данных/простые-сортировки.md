# Простые сортировки

**Простые сортировки** — алгоритмы со сложностью `O(n²)`. Они медленнее эффективных, но проще устроены и хорошо работают на **маленьких** массивах (до 10–20 элементов) и на **почти отсортированных** данных. Именно с них начинают изучение сортировок.

## Сортировка вставками

Массив делится на **отсортированную** и **неотсортированную** части. На каждом шаге очередной элемент из неотсортированной части **включается** в отсортированную на нужное место — сдвигом вправо всех элементов, которые больше него.

```text
INSERTION_SORT(A)
1  for j ← 2 to length(A)
2      key ← A[j]
3      i ← j - 1
4      while i > 0 and A[i] > key
5          A[i + 1] ← A[i]
6          i ← i - 1
7      A[i + 1] ← key
```

**Сложность:** `O(n²)` в среднем и худшем случае. Но если массив **уже отсортирован**, внутренний цикл не выполнится ни разу — `O(n)`. Это делает сортировку вставками хорошим выбором для почти отсортированных данных.

**Устойчива.** Элементы с одинаковыми ключами сохраняют относительный порядок.

## Сортировка выбором

Массив тоже делится на отсортированную и неотсортированную части. На каждом шаге находим **минимальный** элемент в неотсортированной части и меняем его местами с первым элементом этой части.

```text
SELECTION_SORT(A)
1  for i ← 1 to n - 1
2      minIndex ← i
3      for j ← i + 1 to n
4          if A[j] < A[minIndex] then minIndex ← j
5      swap(A[i], A[minIndex])
```

Общее число операций: `n + (n-1) + ... + 1 = n(n-1)/2`. **Сложность:** `O(n²)` **в любом случае** — даже на отсортированном массиве.

**Не устойчива.** Обмен может нарушить относительный порядок равных элементов.

**Особенность:** число **обменов** минимально — не более `n − 1`. Это ценно, когда обмен дорог (например, элементы — большие структуры).

### Квадратичный выбор

Идея улучшения: если `n` — точный квадрат, делим массив на `√n` групп по `√n` элементов. Находим минимум в каждой группе, потом среди «лидеров». Каждый следующий выбор требует не более `√n - 2` сравнений внутри группы плюс `√n - 1` среди лидеров. Итого `O(n√n)` — лучше, чем `O(n²)`.

## Пузырьковая сортировка

Сравниваем пары **соседних** элементов и меняем их местами, если они стоят в неправильном порядке. Проход повторяется, пока массив не упорядочится.

```text
BUBBLESORT(A, n)
1  for i ← n-1 downto 1
2      flag ← false
3      for j ← 1 to i
4          if A[j] > A[j+1] then
5              swap(A[j], A[j+1])
6              flag ← true
7      if not flag then return A
```

**Сложность:** `O(n²)` в среднем и худшем. Благодаря флагу `flag` на отсортированном массиве — `O(n)`.

**Устойчива.** Но на практике используется **только для обучения** — слишком много лишних обменов.

**Особенность:** лёгкие элементы («пузырьки») поднимаются наверх за один проход, а тяжёлые опускаются медленно. Массив `6 1 2 3 4 5` потребует 5 проходов.

## Шейкер-сортировка

Улучшение пузырьковой: проходы идут **то слева направо, то справа налево**. Это убирает проблему «тяжёлых» элементов, которые тонут медленно.

**Сложность:** `O(n²)` в среднем, `O(n)` на почти отсортированном массиве.

**Устойчива.**

## Сортировка Шелла

Модификация сортировки вставками. Вместо включения элемента в подмассив **непосредственно предшествующих** элементов его включают в подсписок с шагом `h`: `A[i-h]`, `A[i-2h]`, ... Массив разбивается на `h` серий, каждая сортируется отдельно. Затем `h` уменьшается, и процесс повторяется, пока `h` не станет равным `1`.

Рекомендуемая последовательность шагов: `1, 4, 13, 40, 121, ...` (`hᵢ₊₁ = 3hᵢ + 1`). Начинают с наибольшего `h`, при котором `h ≥ n/9`.

**Сложность:** `O(n^(4/3))` — быстрее, чем `O(n²)`, но медленнее, чем `O(n log n)`.

**Не устойчива.**

## Реализация на C

```c
#include <stdio.h>
#include <stdbool.h>
#include <stddef.h>

// Вставками
void insertionSort(int a[], size_t n) {
    for (size_t j = 1; j < n; j++) {
        int key = a[j];
        size_t i = j;
        while (i > 0 && a[i - 1] > key) {
            a[i] = a[i - 1];
            i--;
        }
        a[i] = key;
    }
}

// Выбором
void selectionSort(int a[], size_t n) {
    for (size_t i = 0; i < n - 1; i++) {
        size_t minIndex = i;
        for (size_t j = i + 1; j < n; j++) {
            if (a[j] < a[minIndex]) minIndex = j;
        }
        if (minIndex != i) {
            int tmp = a[i];
            a[i] = a[minIndex];
            a[minIndex] = tmp;
        }
    }
}

// Пузырьковая
void bubbleSort(int a[], size_t n) {
    for (size_t i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (size_t j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

// Шейкер
void shakerSort(int a[], size_t n) {
    size_t left  = 0;
    size_t right = n - 1;
    bool swapped = true;

    while (swapped) {
        swapped = false;
        for (size_t j = left; j < right; j++) {
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;
        right--;

        swapped = false;
        for (size_t j = right; j > left; j--) {
            if (a[j - 1] > a[j]) {
                int tmp = a[j];
                a[j] = a[j - 1];
                a[j - 1] = tmp;
                swapped = true;
            }
        }
        left++;
    }
}

// Шелла
void shellSort(int a[], size_t n) {
    size_t h = 1;
    while (h < n / 3) h = 3 * h + 1;

    while (h >= 1) {
        for (size_t i = h; i < n; i++) {
            int key = a[i];
            size_t j = i;
            while (j >= h && a[j - h] > key) {
                a[j] = a[j - h];
                j -= h;
            }
            a[j] = key;
        }
        h /= 3;
    }
}
```

## Итог

- **Вставками** — `O(n²)`, но `O(n)` на почти отсортированных данных. Устойчива.
- **Выбором** — всегда `O(n²)`, но мало обменов. Не устойчива.
- **Пузырьковая** — `O(n²)`, только для обучения. Устойчива.
- **Шейкер** — улучшение пузырьковой с двусторонними проходами.
- **Шелла** — `O(n^(4/3))`, модификация вставками с шагом.
- Простые сортировки хороши для **маленьких** массивов (до 20 элементов).
