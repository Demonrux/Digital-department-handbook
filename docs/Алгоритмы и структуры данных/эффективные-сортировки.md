# Эффективные сортировки

**Эффективные сортировки** — алгоритмы со сложностью `O(n log n)`. Это теоретический предел для сортировок, основанных на **сравнениях**. На практике они используются повсеместно.

## Пирамидальная сортировка

**Пирамида** (binary heap) — это массив, который рассматривается как **почти полное бинарное дерево**. Каждый узел соответствует элементу массива. На всех уровнях, кроме последнего, дерево заполнено полностью; последний уровень заполняется слева направо.

Индексы связаны просто:

```text
Parent(i) = ⌊i / 2⌋
Left(i)   = 2i
Right(i)  = 2i + 1
```

На большинстве процессоров `2i` — это побитовый сдвиг влево, `⌊i/2⌋` — сдвиг вправо. Поэтому операции выполняются очень быстро.

**Свойство пирамиды:** `H[i] ≤ H[2i]` и `H[i] ≤ H[2i+1]` — каждый родитель не больше своих детей. Значит, в корне — минимум.

**Построение пирамиды на том же месте (Флойд).** Нижний слой (листья) уже образует пирамиду. Затем пирамида расширяется влево: каждый новый элемент **просеивается** (sift) вниз до нужной позиции.

**Сортировка:** `n` раз выталкиваем минимум из корня в конец массива, уменьшая размер пирамиды.

**Сложность:** `O(n log n)` в худшем случае. Heapsort «любит» почти отсортированные массивы — фаза построения требует мало перемещений. Среднее число перемещений ≈ `n/2 · log n`.

**Не устойчива.**

## Быстрая сортировка

Реализация парадигмы **«разделяй и властвуй»**. Выбирается опорный элемент `x`, массив разделяется на две части: слева — меньше `x`, справа — больше. Затем каждая часть сортируется рекурсивно.

```text
PARTITION(a, L, R, x)
1  i ← L
2  j ← R
3  repeat
4      while a[i] < x do i ← i + 1
5      while a[j] > x do j ← j - 1
6      if i <= j then
7          swap(a[i], a[j])
8          i ← i + 1
9          j ← j - 1
10 until i > j
```

**Сложность:** в среднем `O(n log n)`, в худшем — `O(n²)`. Худший случай — когда опорный элемент оказывается наибольшим или наименьшим: одна часть содержит `n−1` элементов, другая — `1`.

**На практике** quicksort часто оказывается **оптимальным**: константы в `O(n log n)` малы, сортировка выполняется **без дополнительной памяти**. Ожидаемое число обменов ≈ `(n−1)/6`, сравнений ≈ `n log n`.

**Не устойчива.**

### Как избежать худшего случая

- Выбирать опорный **случайно**.
- Выбирать **медиану из трёх**: первый, средний, последний.
- **Интроспективная сортировка:** если глубина рекурсии превышает `2·log n`, переключаться на heapsort.

## Сортировка слиянием

Тоже парадигма «разделяй и властвуй», но с тремя чёткими этапами:

1. **Разделение** — последовательность из `n` элементов делится на две по `n/2`.
2. **Покорение** — обе половины рекурсивно сортируются.
3. **Комбинирование** — две отсортированные половины **сливаются** в одну.

Рекурсия заканчивается, когда длина последовательности становится равной `1`.

**Процедура Merge** сливает два отсортированных подмассива за `O(n)`. Она копирует их во вспомогательные массивы `L` и `R`, добавляет **пороговые** элементы (бесконечность) и поочерёдно выбирает меньший из двух.

**Сложность:** `O(n log n)` **в любом случае** — и в лучшем, и в худшем. Это главное преимущество перед quicksort.

**Недостаток:** требует `O(n)` дополнительной памяти.

**Устойчива.**

**Применение:** внешняя сортировка больших файлов, сортировка связных списков.

## Реализация на C

```c
#include <stdio.h>
#include <stdlib.h>
#include <stddef.h>

// ===== Пирамидальная сортировка =====
static void heapify(int a[], size_t n, size_t i) {
    size_t largest = i;
    size_t left    = 2 * i + 1;
    size_t right   = 2 * i + 2;

    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;

    if (largest != i) {
        int tmp = a[i];
        a[i] = a[largest];
        a[largest] = tmp;
        heapify(a, n, largest);
    }
}

void heapSort(int a[], size_t n) {
    for (long i = (long)n / 2 - 1; i >= 0; i--) {
        heapify(a, n, (size_t)i);
    }
    for (size_t i = n; i > 1; i--) {
        int tmp = a[0];
        a[0] = a[i - 1];
        a[i - 1] = tmp;
        heapify(a, i - 1, 0);
    }
}

// ===== Быстрая сортировка =====
static void quickSortRec(int a[], long left, long right) {
    if (left >= right) return;

    int pivot = a[(left + right) / 2];
    long i = left;
    long j = right;

    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
            i++;
            j--;
        }
    }

    quickSortRec(a, left, j);
    quickSortRec(a, i, right);
}

void quickSort(int a[], size_t n) {
    if (n > 1) quickSortRec(a, 0, (long)n - 1);
}

// ===== Сортировка слиянием =====
static void merge(int a[], int tmp[], size_t left, size_t mid, size_t right) {
    size_t i = left, j = mid + 1, k = left;

    while (i <= mid && j <= right) {
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    }
    while (i <= mid)   tmp[k++] = a[i++];
    while (j <= right) tmp[k++] = a[j++];

    for (size_t p = left; p <= right; p++) {
        a[p] = tmp[p];
    }
}

static void mergeSortRec(int a[], int tmp[], size_t left, size_t right) {
    if (left >= right) return;
    size_t mid = left + (right - left) / 2;
    mergeSortRec(a, tmp, left, mid);
    mergeSortRec(a, tmp, mid + 1, right);
    merge(a, tmp, left, mid, right);
}

void mergeSort(int a[], size_t n) {
    if (n < 2) return;
    int *tmp = malloc(n * sizeof(int));
    if (tmp == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }
    mergeSortRec(a, tmp, 0, n - 1);
    free(tmp);
}
```

## Итог

- **Пирамидальная** — `O(n log n)` гарантированно, без памяти. Не устойчива.
- **Быстрая** — `O(n log n)` в среднем, `O(n²)` в худшем, но быстрее всех на практике. Не устойчива.
- **Слиянием** — `O(n log n)` всегда, но `O(n)` памяти. Устойчива.
- `O(n log n)` — теоретический предел для сортировок **сравнениями**.
- На практике по умолчанию берут quicksort, но с защитой от худшего случая.
