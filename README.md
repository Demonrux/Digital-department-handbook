# Справочник отдела цифрового развития ССФ СГН

Добро пожаловать! Это единый источник знаний нашего отдела: правила работы, стек, обучающие материалы и задания. Репозиторий живой — любой может предложить улучшение через Pull Request.

## Структура

- [`docs/`](docs/) — обучающие материалы (Git, стек, DevOps и т.д.)
- [`assignments/`](assignments/) — практические задания для новичков
- [`contributors.md`](contributors.md) — список участников отдела
